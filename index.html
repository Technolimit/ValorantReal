Controls and keybinds are under Settings.

    
This game needs a mouse and keyboard. Open it on a computer to play.

    
Sensitivity uses the same scale as Valorant, so you can bring yours over. Stop moving before you shoot: rifles are only accurate below about a quarter of run speed. Every gun has a fixed spray pattern: the overlay at the bottom right shows it next to where your shots landed.

There's no game server: whoever creates a server hosts it in their own browser, and everyone picks an agent on the agent select screen once they're in. The list shows internet servers from every player who has this screen open or is hosting (one player's browser keeps the list, and another takes over when they leave), plus servers in other tabs of this browser. If a server doesn't show up, join with its room code; the host sees it on the agent select screen.

  






  

    
Maps

    
Every map is a JSON file in maps/ that you can edit: walls, materials, sky and lighting, spawns, sites, barriers, rules. Download one to start from, change it in any text editor (the format is explained in MAPS.md), then Import file. Imported maps are kept in this browser and sent to players who join you online.
