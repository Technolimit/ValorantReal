This game needs a mouse and keyboard. Open it on a computer to play.

    
Sensitivity uses the same scale as Valorant, so you can bring yours over. Stop moving before you shoot: rifles are only accurate below about a quarter of run speed. Every gun has a fixed spray pattern: the overlay at the bottom right shows it next to where your shots landed.

  






  

    
Online match

    
No game server: one player hosts in their browser and the others join with the room code. Online matches are deathmatch with abilities off, on the map picked under Maps.

    

      
      
      
      
      
    

    

    

      
      
      
    

    
BroadcastChannel only reaches other tabs of this browser on this site (great for testing; put the windows side by side, since a hidden host tab slows down). PeerJS connects different computers: its public broker only introduces the browsers, then gameplay is sent directly between them.

  






  

    
Maps

    
Maps are JSON files loaded with fetch from maps/. Import your own grid map (see maps/arena.json for the format); imported maps are kept in this browser and sent to players who join you online.
